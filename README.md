**Rent-a-Grandma Hotline** — a one-sentence bizarre startup pitch: a rent-a-grandma hotline where lonely programmers pay $15 an hour for a stranger's grandmother to scold them into eating lunch, drinking water, and going outside. 162 characters, written fresh for this bounty.

`main.py` is its deterministic runner: it writes the pitch to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
